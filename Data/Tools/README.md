# `Data/Tools/`

| Path | Role |
|------|------|
| `Agenda/Unfinished/` | Quick standalone to-dos (`.md` + optional `schedule`) |
| `Agenda/<Mission>/` | Mission folders (main note matches folder name) |
| `Projects/<Project>/` | Project folders (main dashboard note inside) |
| `Repository/New/` | Capture inbox for **Repository → New** |

Empty folders use `.gitkeep` so Git preserves them. Remove `.gitkeep` after you add real files.
